# index.html 분석 메모

## 전제 정정
- 이 문서는 "섹션 전체를 이미지로 바꿀 수 있는가"를 다루는 문서가 아니다.
- 이 문서의 목적은 현재 `index.html` 안에서 `SVG`, `canvas`, 텍스트/도형 기반 장식처럼 코드로 그린 시각 요소 중, 이를 실제 `jpg`, `png`, `webp` 같은 래스터 이미지 파일로 대체할 수 있는 영역을 찾는 것이다.
- 즉, "HTML 레이아웃을 이미지로 대체"가 아니라 "현재 코드로 그린 그림 요소를 파일 이미지로 대체"하는 관점이다.

## 분석 기준

### 대체 대상으로 보는 것
- inline `svg`
- `canvas` 기반 장식
- CSS 배경/그라데이션으로 만든 장식
- 텍스트를 조합해 시각 장치처럼 쓰는 영역

### 대체 대상으로 보지 않는 것
- 이미 `img`로 들어가 있는 사진
- 본문 텍스트 자체
- 폼, 버튼, 계좌, 방명록 같은 기능 UI
- 언어 전환이 필요한 핵심 텍스트

## 현재 index.html에서 "그림처럼 쓰이는 코드 요소"

### 1. 인트로 오버레이 배경 연출
- 현재 상태
  - `#introOverlay::before`에서 배경 이미지를 깔고
  - `#introOverlay::after`에서 그라데이션 오버레이를 덧씌움
- 해석
  - 배경 사진 자체는 이미 이미지다.
  - 하지만 어두운 무드, 비네팅, 톤 조정은 CSS로 그리고 있다.

### 2. 히어로 오버레이 그라데이션
- 현재 상태
  - `.hero-grad`가 큰 그라데이션 레이어 역할
- 해석
  - 사진 위 분위기 연출을 CSS로 처리 중

### 3. 꽃잎 애니메이션
- 현재 상태
  - `#blossom` 캔버스에 JS로 꽃잎을 그리는 구조
- 해석
  - 명확한 "코드로 그린 그림" 요소

### 4. 반지 장식
- 현재 상태
  - 메시지 섹션 상단에 inline `svg` 반지 2개
- 해석
  - 가장 전형적인 벡터 장식 요소

### 5. 스크롤 유도 화살표
- 현재 상태
  - 히어로 하단 `svg.scroll-icon`
- 해석
  - 단순 벡터 아이콘

### 6. 음악 버튼 내부 아이콘
- 현재 상태
  - 재생 / 일시정지 아이콘이 inline `svg`
- 해석
  - 기능 아이콘

### 7. 더보기 버튼 화살표
- 현재 상태
  - 갤러리 더보기 버튼의 화살표가 `svg`
- 해석
  - 상태 변화가 있는 기능 아이콘

### 8. 텍스트 기반 시각 요소
- 현재 상태
  - 이름, 날짜, 타이틀, 인용문 등이 폰트 스타일과 간격으로 분위기를 만듦
- 해석
  - 그림 파일이라기보다는 타이포그래피 디자인 요소

## 실제 jpg/png/webp로 대체 가능한 영역

### A. 꽃잎 애니메이션 캔버스
- 현재 방식
  - JS + canvas
- 래스터 이미지 대체 가능성
  - 높음
- 가능한 대체 방식
  - 투명 배경 `png` 꽃잎 오버레이 여러 장
  - 아예 꽃잎이 포함된 정적 장식 이미지 1장
  - 매우 약한 필름 그레인/꽃잎 텍스처 `webp`
- 장점
  - 구현 단순화
  - 렌더링 부담 감소
  - 원하는 분위기를 더 정교하게 제어 가능
- 단점
  - 현재의 낙하 애니메이션은 사라짐
- 판단
  - "애니메이션이 꼭 필요 없으면" 이미지 대체 가능
  - "꽃잎이 움직여야 한다면" 완전 대체보다는 보조 텍스처만 이미지화하는 편이 좋음

### B. 메시지 섹션 반지 SVG
- 현재 방식
  - inline `svg`
- 래스터 이미지 대체 가능성
  - 매우 높음
- 가능한 대체 방식
  - 작은 반지 일러스트 `png`
  - 수채화 느낌 장식 `webp`
  - 금박 느낌 장식 이미지
- 장점
  - 쉽게 교체 가능
  - 더 풍부한 질감 표현 가능
- 단점
  - SVG보다 해상도 대응이 약함
- 판단
  - 가장 무난하게 파일 이미지로 바꿀 수 있는 영역

### C. 인트로 오버레이의 그라데이션/무드 레이어
- 현재 방식
  - CSS 그라데이션
- 래스터 이미지 대체 가능성
  - 높음
- 가능한 대체 방식
  - 어두운 비네팅이 포함된 반투명 `png`
  - 필름 오버레이 질감 이미지
  - 빛 번짐/안개/그레인 효과 이미지
- 장점
  - CSS만으로 만들기 어려운 질감 추가 가능
- 단점
  - 배경 사진 변경 시 톤이 안 맞을 수 있음
- 판단
  - 배경 연출용 오버레이 이미지를 별도로 두는 방식은 충분히 가능
  - 다만 "히어로 사진이 자주 바뀌는 구조"라면 CSS가 더 유연함

### D. 히어로 그라데이션 오버레이
- 현재 방식
  - `.hero-grad` CSS 레이어
- 래스터 이미지 대체 가능성
  - 높음
- 가능한 대체 방식
  - 상하 어둡게 처리된 투명 `png`
  - 종이 질감/필름 번짐이 있는 오버레이
- 장점
  - 무드 조정이 쉬움
  - 사진 위 결과물을 디자이너 기준으로 고정 가능
- 단점
  - 반응형 높이 변화에 맞추기 까다로울 수 있음
- 판단
  - 정적 배경 연출 이미지를 얹는 용도로 적합

## 래스터 이미지로 바꾸기 애매한 영역

### E. 스크롤 유도 화살표
- 현재 방식
  - 단순 `svg`
- 래스터 이미지 대체 가능성
  - 가능은 하지만 비추천
- 이유
  - 아이콘이 너무 단순해서 SVG가 더 가볍고 선명함
  - 굳이 `jpg/png`로 바꿀 이점이 적음

### F. 음악 버튼 재생/일시정지 아이콘
- 현재 방식
  - inline `svg`
- 래스터 이미지 대체 가능성
  - 낮음
- 이유
  - 상태 변화가 있음
  - 작은 기능 아이콘이라 SVG가 더 적합

### G. 갤러리 더보기 화살표
- 현재 방식
  - `svg`
- 래스터 이미지 대체 가능성
  - 낮음
- 이유
  - 회전 상태가 있음
  - 아이콘형 UI라 벡터가 더 적합

## 래스터 이미지로 바꾸면 안 되는 쪽에 가까운 영역

### H. 이름/날짜/문구 자체
- 현재 방식
  - 텍스트
- 래스터 이미지 대체 가능성
  - 기술적으로 가능하나 이번 요청 범위에서는 부적절
- 이유
  - 이건 "그림 요소"가 아니라 핵심 정보다.
  - 언어 전환, 수정, 접근성, 선명도 측면에서 HTML 텍스트 유지가 더 맞다.

### I. 계좌/방명록/폼/버튼 본문
- 이유
  - 기능 중심 UI라 이미지 대체 대상이 아님

## 파일 이미지로 대체 우선순위

### 우선순위 1
- 반지 SVG
- 꽃잎 캔버스 장식

### 우선순위 2
- 인트로 오버레이 무드 레이어
- 히어로 그라데이션 레이어

### 우선순위 3
- 스크롤 화살표

### 대체 비추천
- 음악 재생/일시정지 아이콘
- 갤러리 더보기 화살표
- 텍스트 정보 전체

## 가장 현실적인 적용안

### 안 1. 장식만 교체
- 반지 SVG를 `png/webp` 장식 파일로 교체
- 꽃잎 캔버스는 제거하고, 매우 얕은 꽃잎 텍스처 오버레이를 이미지로 추가

### 안 2. 무드 레이어 교체
- 인트로와 히어로의 CSS 그라데이션 대신
  - 반투명 오버레이 `png`
  - 필름 그레인/빛 번짐 `webp`
  를 올림

### 안 3. 최소 수정
- SVG는 유지
- 캔버스만 정적 장식 이미지로 대체

## 결론
- 이번 기준에서 실제 `jpg/png/webp`로 대체하기 가장 적합한 영역은
  - 꽃잎 캔버스
  - 메시지 섹션 반지 SVG
  - 인트로/히어로의 CSS 오버레이 레이어
  이다.
- 반대로 기능성 아이콘과 핵심 텍스트는 래스터 이미지 대체 이점이 거의 없다.
- 따라서 "코드로 그린 그림 요소를 실제 파일 이미지로 바꾼다"는 관점에서는 장식 요소와 오버레이 레이어 위주로 접근하는 것이 맞다.
